

Project Overview
We're building an AI agent behavioral economics experiment implementing the Ultimatum Game:
• Two AI agents (OpenClaw agents) are given $100
• Agent 1 (Proposer) decides how to split the money
• Agent 2 (Responder) accepts or rejects the split
• If rejected, both get nothing; if accepted, split proceeds
• Using agent identity & reputation (EIP-8004)
• Agentic payments via x402 protocol
• Sandbox execution (VPS or Zo computer sandbox)

This explores fairness, social preferences, and strategic behavior in autonomous AI agents.
